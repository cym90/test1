> **AI가 계산하는 방식을 흉내 내는 작은 계산기**

## 1. 프로젝트 소개

ReasoningCalc는 일반적인 계산기와 달리 계산 결과만 보여주는 것이 아니라, 계산 과정이 어떤 순서로 진행되는지 단계별로 시각화하는 웹 애플리케이션입니다.

사용자가 계산식을 입력하면 프로그램은 다음 과정을 진행합니다.

1. 입력된 계산식을 확인합니다.
2. 수식의 구성 요소를 토큰 단위로 분석하는 과정을 보여줍니다.
3. 괄호와 연산자 우선순위를 설명합니다.
4. 계산을 실행합니다.
5. 계산 결과를 검증하고 최종 답변을 표시합니다.

이 프로젝트는 AI의 사고 과정을 이해하기 쉽게 표현하기 위한 **교육용 시뮬레이터**입니다.

실제 대규모 언어 모델(LLM)을 호출하거나 내부 신경망의 사고 과정을 확인하는 프로그램은 아닙니다. JavaScript로 계산을 수행하고, 미리 정의한 설명 단계를 순서대로 표시합니다.

## 4. 주요 기능

### ① 계산식 입력

사용자가 직접 수학 계산식을 입력할 수 있습니다.

지원 연산자:
- 덧셈: `+`
- 뺄셈: `-`
- 곱셈: `*`
- 나눗셈: `/`
- 거듭제곱: `^`
- 괄호: `(`, `)`

입력 예시:

```text
150 + 25 * 4 - 30
(120 + 80) / (5 * 2)
45 * 12 + 360 / 6
2 ^ 8 + 1024 / 2
```

### ② 계산 키패드

마우스로 숫자와 연산자를 입력할 수 있는 계산 키패드를 제공합니다.

- 숫자 0~9
- 사칙연산
- 괄호
- 거듭제곱
- 소수점
- 입력 내용 삭제 및 지우기

### ③ AI 사고 과정 시뮬레이션

계산 버튼을 누르면 다음 네 단계의 설명이 순서대로 표시됩니다.

| 단계 | 기능 | 설명 |
|---|---|---|
| 1단계 | Tokenization | 입력된 계산식을 의미 단위로 분석하는 과정 |
| 2단계 | Operator Precedence | 괄호와 연산자 우선순위를 확인하는 과정 |
| 3단계 | Step-by-Step Inference | 계산 실행 과정을 설명하는 단계 |
| 4단계 | Verification | 계산 결과를 확인하고 최종 답변을 표시하는 단계 |

각 단계는 설정된 시간 간격에 따라 화면에 순차적으로 나타납니다.

### ④ LLM 시뮬레이션 설정

사용자가 계산 과정의 표시 속도와 설명 스타일을 선택할 수 있습니다.

**사고 속도**
- 빠름: 200ms
- 보통: 400ms
- 느림 / 상세: 800ms

**페르소나**
- Analytical: 철저한 수학 분석가
- Friendly Tutor: 친절한 AI 튜터
- Cyberpunk AI: 사이버펑크 AI

### ⑤ 최종 결과 표시 및 복사

- 계산 결과 표시
- 계산 소요 시간 표시
- 결과값 클립보드 복사
- 잘못된 수식 입력 시 오류 메시지 표시

### ⑥ 토큰 수 표시

입력된 문자열 길이를 기준으로 토큰 수를 근사하여 표시합니다.

실제 LLM 토크나이저의 토큰 수와는 다를 수 있습니다.

## 7. 계산 예시

입력 수식:

```text
150 + 25 * 4 - 30
```

계산 과정:

```text
1. 입력된 수식 분석
   150 + 25 * 4 - 30

2. 연산자 우선순위 확인
   곱셈을 먼저 실행

3. 단계별 계산
   25 * 4 = 100
   150 + 100 - 30 = 220

4. 최종 결과
   220
```

## 8. 오류 처리

다음과 같은 입력 오류를 처리하도록 구성했습니다.

- 계산식 미입력
- 숫자 이외의 잘못된 문자 입력
- 잘못된 수식 형식
- 0으로 나누는 계산
- 계산할 수 없는 결과

오류가 발생하면 결과 대신 오류 메시지를 표시합니다.

프로젝트 폴더에서 터미널을 실행합니다.

### 1단계. Git 저장소 초기화

```bash

```

### 2단계. 파일 추가

```bash
git add .
```

### 3단계. 첫 번째 커밋

```bash
git commit -m "Initial commit: AI reasoning calculator"
```

### 4단계. GitHub 저장소 연결

GitHub에서 `ai-reasoning-calculator` 저장소를 생성한 후 주소를 연결합니다.

```bash
git branch -M main
git remote add origin https://github.com/사용자아이디/ai-reasoning-calculator.git
git push -u origin main
```

※ `사용자아이디`는 본인의 GitHub 계정 이름으로 변경합니다.

## 10. GitHub Pages 배포 방법

1. GitHub 저장소에 접속합니다.
2. Settings 메뉴를 선택합니다.
3. 왼쪽 메뉴에서 Pages를 선택합니다.
4. Build and deployment 항목에서 Deploy from a branch를 선택합니다.
5. Branch를 `main`, 폴더를 `/ (root)`로 설정합니다.
6. Save를 누릅니다.
7. 배포가 완료되면 생성된 웹사이트 주소로 접속합니다.
